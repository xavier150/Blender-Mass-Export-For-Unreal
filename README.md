# Blender Mass Export For Unreal

A script to batch-export multiple assets from a Blender file to Unreal Engine using the [Blender-For-UnrealEngine addon](https://github.com/xavier150/Blender-For-UnrealEngine-Addons).

![Export results in the VS Code terminal](https://github.com/xavier150/Blender-Mass-Export-For-Unreal/wiki/images/terminal_result.png)

> **Note:** The configuration files are currently hardcoded and set up for development of the [MMVS video game](https://github.com/xavier150/MMVS). A command-line interface for controlling the export is planned for a future update.
